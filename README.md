## GitHub Pages Deployment Instructions

The website is **100% static** (pure HTML5, CSS3, Vanilla JavaScript, and SVG assets) with zero backend, database, or build dependencies.

### Steps to Deploy:

1. **Create a GitHub Repository**:
   - Name your repository `syntreva` (or any custom name).

2. **Commit and Push**:
   ```bash
   git init
   git add .
   git commit -m "Deploy: Syntreva Future Technology Ecosystem in Sage Green and Charcoal"
   git branch -M main
   git remote add origin https://github.com/YOUR-GITHUB-USERNAME/syntreva.git
   git push -u origin main
   ```

3. **Enable GitHub Pages**:
   - Go to your repository on GitHub: **Settings** → **Pages**.
   - Under **Build and deployment** → **Source**, select **Deploy from a branch**.
   - Set the Branch to `main` and the folder to `/ (root)`, then click **Save**.

4. **Live URL**:
   Your website will be live at:
   ```
   https://YOUR-GITHUB-USERNAME.github.io/syntreva/
   ```
